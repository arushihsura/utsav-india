Google OAuth & Token Architecture

This project separates Identity Verification from Application Authorization:

  1. Google Identity Services: The client authenticates with Google OpenID Connect, receiving a signed Google ID token.
  2. Backend Token Verification: Flask verifies the signature, issuer (accounts.google.com), and audience using google-auth.
  3. Application JWT: Flask issues an independent HS256 JWT containing the SQLite user ID and expiry time.
  4. Authorization: Protected endpoints validate the application JWT via the @require_auth decorator.
